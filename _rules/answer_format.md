# 回答格式行为准则

## 规则 1：纠正答案时保留原始错误理解

当用户回答问题后被纠正，答案注释中必须同时包含：

1. **我先前的理解** — 用户原始的回答（即使有错误也原文保留）
2. **✅ 纠正后的理解** — 修正后的正确版本

目的：用户复习时能清楚看到"我之前错在哪里"以及"正确的应该是什么"，形成对比，加深记忆。

### 示例格式

```python
#    我先前的理解：
#      ...（用户的原始回答，逐条列出）
#    ✅ 纠正后的理解：
#      ...（修正内容，对错误点一一回应）
```

## 规则 2：追加提问不覆盖，按对话顺序向下堆叠

当用户对已有的注释内容提出新的追问时：

1. **不修改/覆盖已有的注释**，保留原样
2. 在原有注释后面新增一段，以 `【追问：...】` 开头标记新的问题
3. 同样按"我先前的理解 / ✅ 纠正后的理解"双栏格式整理

目的：保留完整的思考脉络，用户复习时能看到"先学了什么 → 然后产生了什么疑问 → 最后怎么解决的"这个完整链条。

### 示例格式

```python
#    【追问：用户的疑问摘要】
#    我先前的理解：
#      ...（用户基于前面内容的新理解/疑惑）
#    ✅ 纠正后的理解：
#      ...（针对新问题的回答）
```
